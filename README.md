# Nettty — The Brain of God

The Netty Particle Model, by Mark William Miller.

## Seven-layer animated particle map

Open **[visualization/index.html](visualization/index.html)** in your browser. Explore all seven spaces together, isolate a layer, orbit the scene, or play the guided visual journey.

See [visualization/README.md](visualization/README.md) for controls and visual direction. The source design is [Project Netty Anon.pdf](design/Project%20Netty%20Anon.pdf).

The existing Java / Java3D project is in `src/`, with its Maven configuration in `pom.xml`.
