The explanation I challenge
Random mutation and natural selection is a heuristic algorithm.

Imagine an Earth-mass population. Every cell tries a unique DNA sequence each second, for four billion years. No repeats, anywhere.

Every added base quadruples the possibilities.

Assumptions & scope

Four letters per position: 4ⁿ sequences for n base pairs. The complementary strand is determined, not another independent set of choices. Trials = (Earth mass ÷ cell mass) × seconds.

This counts exhaustive enumeration. It does not give the probability of evolution: selection retains inherited changes, and evolution does not require trying every possible DNA sequence.
