# 0.1.0 — First documentation release

Organized portable guidance, the maintained Talisman architecture documentation and linked references,
Place/Character example documents, lifecycle templates, theme examples, adoption instructions and a local
expandable contents view. No new experimental executables are included. This release is intended for
physical inclusion in projects and refinement through use; it does not claim downstream adoption or
implemented runtime/database behavior. Component-specific examples remain examples.
