0.1.13 prepares the local-workshop → read-only Tassy rehearsal → read-only Moonbeam delivery profile,
typed AI context, durable browser workspaces with Archive/Reinflate, compiled Morph packages, a shared
press-and-hold radial interaction contract and baseline-bound Place package exchange. The
[curation record](docs/COLLECTED-FINDINGS-0.1.13.md) names exact source bytes and dispositions. No runtime,
database, public delivery, provider, device, consumer installation or release publication is claimed.

The release also supplies a component-publication plan validator and owner-adapter interface. It pins
the selected component/version, owner package digest, descriptor and exact file closure, then requires an
immediate destination guard plus exact remote-selection and public-served receipts. Sam's source review
confirmed that no current owner command implemented the complete interface. Workboard's four-field,
fail-closed call and Tassy's reusable adapter have since landed with focused tests and remain disabled.
The concrete operator-machine transport and live Moonbeam receipt remain named dependencies rather than
a delivered production-publication claim.

This release adds Voice Lab package shape and the minimal stack decision for self-hosted speech-to-text,
text-to-speech and explicit recordings; no server, browser controller, model, voice, recording, deployment or
consumer adoption is supplied. Prior 0.1.7 behavior-executor material remains part of the Kit.
