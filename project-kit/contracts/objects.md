# Standard objects — source binding pending

Mark requires the shared [Morph language](morph.md), grounded in actual native definitions and owning
codecs. Slice and Thinian/Rougish are editors/projections of that language, not private format owners. MPK must not invent a substitute JSON schema and call it native. No standard object template
is shipped in this release. Exact reusable source examples are pending the data-sharing approval and
Slice owner confirmation; a discovered source path alone does not establish authority or acceptance.

## Required contract and worked example

The completed update must pin actual source revision, owning codec/validator and complete example bytes.
Describe definition versus placed instance, stable identities for edits and new identities only for deliberate clones/new objects,
immutable revisions, provenance, complete Morph geometry/Mapping/Resting poses, motion endpoints,
materials/media and exact dependency revisions. Specify placement units, axes and transforms. Separate
creature/Character bindings from game-owned session state and rules. Keep Place authority explicit.

Document the actual returned-dataset layout, manifest, dependency closure and receiver entrypoint,
validation errors, conflict/replay behavior, durable receipt and exact readback. Include a complete
worked local authoring → returned dataset → native validation → supported import → receipt/readback
example drawn from actual evidence. Structural validation only proves document shape; native validation
and successful admission need the owning implementation and observed results.

Rougish should return data conforming to that verified contract. Easy import is an intended outcome,
not yet proven. All three labs adopt the updated documentation before further software work;
implementation proof continues separately. Keep the all-current-accepted-Morph collection requirement; a worked subset cannot replace it.

## First-practice motion lesson

Beetle's static comparison found all ten local candidates lacked required native top-level stances and
two motion keyframes, despite passing their staging validator. Interpolation also differed. See the
[reported evidence and proposed correction](../docs/DELIVERY-GATES.md). The completed worked example
must use actual native-validated fixture bytes and a codec-specific motion example with resolved stance
references and keyframes. Preserve motion semantics deliberately; renaming an interpolation label does
not prove equivalent motion. Native geometry review remains necessary for the wing representation.

The [return/update cycle](morph-return-cycle.md) governs independent offline compendia, identical native
authoring/payload definitions, plural content ZIPs and same-ID guarded replacement.

Partial Stances, general geometry, nested instances and stage Metamorph semantics follow the shared
language. Earlier candidate/profile details below are implementation evidence, not universal restrictions.
