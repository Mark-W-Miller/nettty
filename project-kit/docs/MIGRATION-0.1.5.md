# Adopt MPK 0.1.5

Historical migration note: the GPT-independent/optional-only AI framing below is superseded by
[0.1.6](MIGRATION-0.1.6.md). Earlier release archives remain unchanged.

This extends 0.1.4 with [Intentions as lazy campaign simulation](../contracts/campaign-simulation.md)
and [Derek's worked design scenario](../examples/derek-campaign-heartbeat.md). Preserve earlier releases,
local guidance, saved worlds and the existing universal Morph/Metamorph/console contracts.

- Classify enduring dispositions/goals as typed Character/campaign extensions, not unrestricted base-Morph
  behavior. Keep canonical definition revisions separate from persistent instance/campaign state.
- Declare dormant state, last-resolved campaign time, Place/presence, relationships, commitments and due
  conditions. Multiple views reference the same identity; do not fabricate clones for materialization.
- Plan explicit GM-authorized logical time operations with bounded interest-driven resolution and clear
  coarse/detailed transitions. Do not install a 24/7 process or automation through documentation adoption.
- Pin audit inputs, rules, random seed/draw sequence, proposals/effects, conflict outcomes and next-due
  state. Prove atomic world updates; independent per-item native saves are not that capability.
- Define replay/undo and restore authority. Keep interpretation optional; typed runtime must work without
  GPT. Missing constructs/codecs/coordinator remain implementation dependencies, not model fallback.
- Adopt exact Kit version/digest deliberately and return a receipt. No consumer upgrade, native runtime,
  database mutation or continuous simulation is performed or claimed by this release.

## Physics prerequisite inventory

Record physics as a future optional adapter. First pin Place coordinates, surfaces/volumes, fields,
active region and fixed-step clock; then identify native physical proxies and transform ownership.
Do not select an engine, serialize its opaque state into canonical content, or claim dynamics/fluid
support during documentation adoption. Preserve authored Motion/Path and game-rule authority boundaries.
