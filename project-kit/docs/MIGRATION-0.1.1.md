1. Preserve 0.1.0 and already dispatched archives. Compare manifests and replace only the copied Kit
   base; retain project root guidance and local extensions. Send active Patchers explicit supplements.
2. Read the new Place, object and native-content contracts. Place requires actual numeric height and
   aligned texture. Missing data stays a reported gap; no default elevation may fabricate terrain.
3. Place v2 replaces the earlier illustrative numeric defaults with an incomplete authoring form.
   Null source bindings must be filled deliberately using the receiving native contract. The schema
   checks only proposed shape; it cannot establish native acceptance.
4. Reconcile local database-adoption/scene supplements against shared contracts. Preserve local game
   assignments and intentional deviations; they are not automatically promoted to universal requirements.
5. Adopt version 0.1.1 and exact manifest digest in a receipt, with accepting owner/date, project revision,
   local extensions and gaps. Documentation adoption does not establish import or runtime acceptance.

Known limitations: no all-Morph export, verified Slice object template, native-validated worked fixture
or successful Insect Wars admission/readback is included. Continue those goals separately. Mark's latest
request authorizes this documentation release without waiting for import completion. Rougish can adopt
