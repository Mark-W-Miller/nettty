# Include and update the Kit

1. Copy the whole release folder into your repository as project-kit/ and retain manifest.json.
2. Add a short link from your root README and AGENTS.md. Preserve existing project guidance.
3. Record Kit version, content digest, adoption date, accepting owner and local extension paths in your
   project notes. The example receipt below is a blank form, not evidence adoption has happened.
4. Commit the copied documentation with the project changes that adopt it. Your full source ZIP now
   contains its own architecture context. Read the guide and relevant contracts, not every historical file.
5. For an update, compare old/new inventories and release notes; review local additions and intentional
   deviations. Replace only the base documentation deliberately, preserve project work, and record the new
   version. No silent synchronization, scripts or database operations are required.

Version: <release>; digest: <manifest content_digest>; adopted: <actual date>; owner: <name>;
local extensions: <paths>; deviations: <notes>; project source revision: <commit>.
