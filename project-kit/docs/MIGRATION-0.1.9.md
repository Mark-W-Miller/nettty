# Adopt MPK 0.1.9

This release adds `VERSION-0.1.9.md` to the Kit root. Its filename lets you see the version directly in
Finder or another directory listing. The marker is included in the release manifest and tagged bytes.

Use the [published-release installer](INSTALLING-PROJECT-KIT.md) to update `project-kit/` and its official
release pin. Exact folder replacement removes superseded shared Kit files and old version markers.
Preserve `project-kit-local/`, its index/findings/handoffs, root guidance and consumer implementation.
Do not remove local supplements simply because a shared release has changed.

A marker is a useful visible label; the manifest and source tag establish exact release identity.
Installation receipts prove copied bytes, not consumer commits, runtime implementation or acceptance.
All 0.1.8 guidance and collection/installation workflows remain included.
