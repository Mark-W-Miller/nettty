# Moondance Project Kit 0.1.0

A complete, physically copyable collection of Moondance architecture documentation, requirements,
templates and reusable reference material. Start with [the Kit guide](MOONDANCE-PROJECT-KIT.md), or open
[the expandable contents view](inspect/index.html).

Copy this entire folder into `project-kit/` in your project. Follow [adoption and updates](docs/ADOPTION.md).
There is nothing to install or execute. Keep your project's own AGENTS.md and ownership intact, and add a
link there to this Kit. Coders implement the framework in the project; the Kit records our thinking.

This release includes the maintained Talisman architecture as explicitly labelled reference documents.
See [reference authority](reference/README.md). Those documents describe their recorded Talisman source,
not proof of the consuming project's behavior. Improve the Kit deliberately as experience identifies gaps.
